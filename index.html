Why inference uses more GPUs

Weights: Model parameters must reside in accessible memory. Lower-precision weights reduce their footprint, though real quantization adds metadata overhead.

KV cache: Context length and concurrent sequences increase attention-state memory even when model parameters stay unchanged. Estimates assume BF16 KV-cache values.

Prefill: Input prompt processing is highly parallel and often compute-intensive; long contexts increase attention work and time to first token.

Decode: Autoregressive token generation repeatedly executes Transformer layers. At low batch sizes it is frequently limited by memory bandwidth.

Scaling: Quantization, better attention kernels, cache reuse, batching, smaller specialized models, and optimized sharding may help before adding GPUs.

Model footprint = parameters (billions) × bytes/weight (decimal GB). KV = 2 × layers × KV heads × head dimension × cached tokens × 2 bytes × concurrency / 10⁹.
